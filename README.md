# STAT-663-001_US_Accidents
STAT-663-001 Studio: Reproducible analysis of US Accidents (2016-2023)


### Data Access

**Source** The data is freely available https://www.kaggle.com/datasets/sobhanmoosavi/us-accidents?resource=download

**Steps**
1. Create an account in Kaggle if you do not have one yet.
2. Log in and navigate to this website. 
3. Click Download.
4. Click Download dataset as zip
5. This will dowload a zipped folder with a large CSV document in it. (It may take a moment)
6. Extract this document and save it in \Data
